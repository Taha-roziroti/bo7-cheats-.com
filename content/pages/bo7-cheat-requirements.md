# Black Ops 7 cheat system requirements

Before buying anything, check your PC.

Seriously. There's no point getting excited about a product, choosing a plan and then finding out your Windows configuration doesn't meet the requirements.

These **Black Ops 7 cheat system requirements** cover the operating system and security settings listed for the BO7 package, along with the extra requirements associated with Cloud DMA.

There are two sets of details to understand, so let's keep them separate.

## Windows requirements for the BO7 package

The supplied Black Ops 7 product page lists Windows 10 and Windows 11 as supported operating systems.

It also specifies four security settings:

| Setting | Required status |
|---|---|
| HVCI | ON |
| Core Isolation | ON |
| TPM | ON |
| Secure Boot | ON |

These requirements should be checked before purchasing.

Having Windows 10 or 11 installed doesn't automatically confirm that every required setting is enabled.

## Black Ops 7 cheat compatibility and Cloud DMA

The main BO7 package lists Cloud DMA as required for full functionality on supported builds.

The Cloud DMA product has additional requirements because it uses a Hyper-V-based environment on a single Windows PC.

Its listed requirements include:

- Windows 10 or Windows 11, 64-bit
- Intel VT-x or AMD-V enabled in firmware
- Hyper-V role enabled during guided setup
- Minimum 8 GB RAM
- 16 GB RAM recommended
- Stable broadband internet

Windows Pro, Enterprise and Education are recommended for the Hyper-V setup. Follow the installer notes for your particular edition.

## What else do I need?

The Cloud DMA listing also identifies three separately purchased requirements:

- GREENWARD
- Static Server
- AWS

All three are listed as required purchases. Static Server and AWS are separate products, so don't count them as the same thing.

Check the [Cloud DMA setup page](/cloud-dma/) for the full product details.

## What about the HWID Spoofer?

The separate HWID Spoofer product lists Windows 10 and Windows 11, 64-bit, administrator rights for spoofing and cleanup, and a stable internet connection.

It also lists HVCI, Core Isolation, TPM and Secure Boot as enabled requirements.

Black Ops 7 appears under the Ricochet section of its supported-games list.

You can read more on the dedicated [BO7 HWID Spoofer page](/hwid-spoofer/).

## Before you purchase

Use this checklist to make sure you've checked the information that matters:

- [ ] Windows version checked
- [ ] 64-bit requirement checked for Cloud DMA
- [ ] HVCI enabled
- [ ] Core Isolation enabled
- [ ] TPM enabled
- [ ] Secure Boot enabled
- [ ] CPU virtualization available and enabled
- [ ] RAM requirement checked
- [ ] Internet connection checked
- [ ] Separate Cloud DMA dependencies reviewed

One last thing: these are the requirements listed by the supplied product pages. Product compatibility can be specific to the Windows edition and supported software build, so check the current installation documentation before purchasing.

If your PC meets the listed requirements, the next step is to look at the actual [Black Ops 7 cheat package and its features](/).
